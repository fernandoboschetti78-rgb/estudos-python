# estudos-python
repositório com projetos de estudo para meu aprendizado em python

os projetos nele são:
- calculadora.py: uma calculadora bem simples via terminal
- leitor_par_ou_impar.py: verifica se um numero é par ou impar
- verificador_de_senhastest.py: um teste de criar senhas e verifica-la para aprender while
- crieloops.py: um criador de loops para testar for in range e variaveis em () de range e time.sleep
- listas.py: um codigo para testar listas, usando while para adicionar strings as listas e dando print nelas
- dicionario_cores.py: um dicionário de cores para testar lower, strip, dicionários e while dentro de if,else e elif.
