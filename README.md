# estudos-python
repositório com projetos de estudo para meu aprendizado em python

os projetos nele são:
- calculadora.py: uma calculadora bem simples via terminal
- leitor_par_ou_impar.py: verifica se um numero é par ou impar
- verificador_de_senhastest.py: um teste de criar senhas e verifica-la para aprender while
- crieloops.py: um criador de loops para testar for in range e variaveis em () de range e time.sleep
- listas.py: um codigo para testar listas, usando while para adicionar strings as listas e dando print nelas
- dicionario_cores.py: um dicionário de cores para testar dicionários e funções def
- Acalculadora.py: calculadora que calcula expressões, para testar eval, .replace e try/except
- rpg.py: um rpg de texto para testar classes e funções
- painel.py: um teste de tkinter que cria pastas, arquivos e copia o próprio código, não consegue copia-lo se for transformada em um executavel
- adv_cara_ou_coroa.pyw: um joguinho de adivinhar se a moeda é cara ou coroa
- cara_ou_coroa.py: fala se é cara ou coroa
- calc.py: uma calculadora com o tkinter que calcula expressões
